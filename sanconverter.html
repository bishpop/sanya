Hold & Roll Logic (Lane 7)

Lane 7 (index 6) acts as a state marker. If a hold/roll is active here, standard key assignments are overridden.

Revert Logic

The Converter features a powerful revert function. It accurately reverts all Audition BeatUp .slk and all Audition One-Two Party .slk files back into a clean Stepmania .SSC file, preserving patterns and BPM data.

05 · Legacy Conversion

Controlled random patterns, kept explicit.

This optional mode detects specific Arrow Vortex combinations to generate highly controlled random patterns.

Arrow Vortex KeyBeat Up .SLK KeyPattern Logic (Muster)
7nRandom key — max. 2 Jacks
7 + 1nRandom LEFT (7,4,1) — max. 3 Jacks
7 + 2nRandom RIGHT (9,6,3) — max. 3 Jacks
7 + 3nRandom — no repeat (No Jacks)
7 + 4nOnly Jacks — same random key spam max. 6

All other patterns will be processed normally.
