SanConverter · Private Build · v1.4.4

A converter built around the chart.

Converts .SM and .SSC files to .SLK, with dedicated logic for Beat Up and One-Two Party, and reverts .SLK files to clean .SSC. Maintained privately alongside its successor Au Converter.

01 · v1.4.4 Highlights

What is inside v1.4.4.

The overhauled level calculator, eye-care themes, SLK utilities, and analyzer fixes that preceded the multi-mode Au Converter architecture.

  1. 01

    Level calculation overhaul

    Fair scaling with Math.Min caps, TotalMadi integration for structural speed logic, and an incremental +0.4 bonus for every 10% of stair patterns.

  2. 02

    10+ new designs

    Cherry Blossom, Cobalt Sky, Cool Revival, and eye-care themes such as Nord, Gruvbox, Solarized Dark, and Zen Matcha.

  3. 03

    SLK duplicate remover

    One-click cleanup for overlapping n notes, automatic row shifting, and safe _fixed.slk output.

  4. 04

    Analyzer and bug fixes

    Accurate Total Keys metrics, corrected UniformGrid overlap, and a better balance between long and short song pattern ratios.

02 · Charting logic

Know exactly what the converter writes.

.SM and .SSC convert to .SLK. The converter also reverts Audition Beat Up and One-Two Party .slk files to clean StepMania .SSC.

Beat Up 8 Structure

Arrow Vortex KeyBeat Up .SLK KeyComment
1, 2, 37, 4, 1Specific Note assignment
4, 5, 69, 6, 3Specific Note assignment
8sSpace
M*Finish MoveShift + 8 (Mine on 8th Lane)
7 + 8fFinish Move without Space
n* + 7 + 8Note + FinishNote Array {1,3,4,6,7,9}
n + MDouble Note (hidden)M on lane 7
n + M + MTriple Note (hidden)M on lane 7 & 8
  • Random Key: A note stated as n in the .slk which Audition can read, randomly generated using a no Jack-Logic.
  • M: Mine.

Hold & Roll Logic (Lane 7)

Lane 7 (index 6) acts as a state marker. If a hold/roll is active here, standard key assignments are overridden.

StateActive LaneKey PoolConstraint
2 (Hold)Lane 1 (Left){7, 4, 1}Max 2 jacks in a row
2 (Hold)Lane 2 (Right){9, 6, 3}Max 2 jacks in a row
2 (Hold)Lane 1 + 2{7,4,1,9,6,3}Max 2 jacks in a row
4 (Roll)Lane 1 (Left){7, 4, 1}No direct repeat (no Jacks)
4 (Roll)Lane 2 (Right){9, 6, 3}No direct repeat (no Jacks)
3 (End)—Resets to BU8—

03 · Legacy conversion

Controlled random patterns.

This optional mode detects specific Arrow Vortex combinations to generate highly controlled random patterns. All other patterns are processed normally.

Arrow Vortex KeyBeat Up .SLK KeyPattern Logic
7nRandom key — max. 2 Jacks
7 + 1nRandom LEFT (7,4,1) — max. 3 Jacks
7 + 2nRandom RIGHT (9,6,3) — max. 3 Jacks
7 + 3nRandom — no repeat (No Jacks)
7 + 4nOnly Jacks — same random key spam max. 6
