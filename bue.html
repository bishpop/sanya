05 · Core Features

Built around the chart, not around the menu.

BeatUp Engine combines timing, gameplay, chart editing, project files, patching and visual customization into one focused toolset.

01

Timing & Judgment

Gameplay graphics and hit detection use one time base, with configurable Perfect timing and refined Great, Cool, Bad and Miss behavior.

02

Chart Editor

Receptor Bar, Split View, vertical or horizontal canvas, waveform, beat/MADI navigation, selection, copy/paste replacement and undo/redo.

03

Project Files

.bu projects keep audio, BPM, offset, notes, speed and saved playback position together for a complete editing session.

04

Theme Editor

Change the core interface colors, waveform, minimap and Receptor Bar appearance with a live preview and persistent theme.ini themes.

05

Patcher

Validate required content, download new patches, recover missing files and apply each song's configured timing offset.

06

Chance & Challenger

Rapid, Vanishing, Wave, Inverted, Speed Up and Halfway Chance modes, with optional Challenger Mode for stricter runs.

Current Editor Layout

7 · 4 · 1 · 9 · 6 · 3 · SP · F

Number keys 1–8 follow the editor columns. The editor can show the Receptor Bar or the classic position line, and the bar scales with the resizable Split View.

Everyday Controls

F1 Game · F2 Editor · F3 Split View · F4 Metronome · F5/Space Play/Pause · F6 Auto-Play · F7 Stop/Reset.

Ctrl+Shift+S Save .bu · Ctrl+Shift+E Export .slk · Ctrl+Shift+V Export .ssc · Ctrl+S Sound Settings · F11 Fullscreen.

06 · Release

v0.6.1 is focused on editor/game parity.

The latest release adds the in-game Receptor Bar to the Chart Editor and makes the Patcher use each song's own timing offset, while keeping v0.6 projects, charts, themes and content compatible.

BeatUp Engine v0.6.1

A focused chart-editor and Patcher timing update.

Receptor Bar in the Chart Editor with six arrow receptors, Space and Finish Move.
The same game assets are used so editor and gameplay receptor sizing stay aligned.
Receptor Bar scales with column width and the resizable Split View in both layouts.
Theme Editor adds Line/Receptor Bar selection plus Band, Icons and Edges colors.
Patcher timing now reads the offset of each song instead of one fixed value.
Receptor visuals were refined, Space/Finish Move assets use their full size, and arrow consistency was fixed.
