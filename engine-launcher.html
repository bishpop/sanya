01 · Launcher Architecture Showcase

Controlled access. Unified deployment.

Every tool in the suite launches from one verifiable workspace with shared session state and automated updates.

  1. Hardware-Bound Auth Gate

    Sign in or create an account tied to your PC's unique MachineGuid, C:\ volume serial, and CPU ProcessorId. New registrations enter Pending Approval until an administrator approves module permissions.

  2. Suite Hub & .enc Deployment

    Streams remote versions.json metadata, compares local PE FileVersion & installed_versions.cfg against server releases, and unpacks encrypted module packages seamlessly into apps/.

  3. Theme Studio & Session Sync

    Persists dark glassmorphism themes, window backdrop blur preferences, and shared .bue_session credentials across BeatUp Engine, Silencer, and Au Converter.

02 · Architecture & Capabilities

Engineered for speed and format accuracy.

Core capabilities built directly into Engine Launcher v1.3.2.0 inside the private Engine Suite.

  1. 01

    Hardware-Locked Account Security

    Combines the Windows Registry 64-bit MachineGuid, system drive volume serial number, and CPU ProcessorId signature into a deterministic HWID. Prevents credential sharing across unauthorized machines.

  2. 02

    Per-Module Permission Whitelisting

    Approved accounts receive granular tool entitlements (AllowedTools) from the server, unlocking only the specific suite modules assigned to that charter or tester.

  3. 03

    Automated Encrypted Package Delivery

    Downloads encrypted .enc archives directly via HTTPS, unpacks them cleanly into per-app directories inside apps/, tracks local versions via PE headers and installed_versions.cfg, and preserves user charts.

  4. 04

    Cross-Suite Single Sign-On

    Writes an authenticated session profile containing Username, CharterName, and avatar metadata that downstream tools like BeatUp Engine v1.4.1 and Au Converter v1.5 automatically consume.

  5. 05

    Self-Updating Architecture

    Detects newer launcher builds on startup, displays a non-intrusive top-bar UPDATE AVAILABLE badge, stages EngineLauncher.update.exe, and cleans up stale .old binaries automatically.
