01 · Silencer Workflow Showcase

Drop a track. Lock exact measure zero.

Silencer automates silence trimming, measure-zero offset detection, and Vorbis routing tailored directly for SLK charts.

  1. Drag & Drop Analysis Metrics

    Calculates exact Tempo (BPM), Audio Offset down to millisecond precision (-0.353s), Start MADI, Total MADI, and Integrated LUFS (-8.0 target toggle).

  2. Smart Routing & Vorbis Bitrates

    Uses the Silence Wav toggle to route WAV → Silence OGG and FLAC/MP3/M4A → Convert WAV automatically across 7 selectable Vorbis bitrates (64k to 320k, 96k recommended).

  3. Interactive Timing Editor & Diagnostics

    Includes fine-grained 1/4, 1/8, 1/16 beat grid nudging and ±0.001s offset controls alongside a styled Catppuccin console and Explorer context menu integration.

02 · Architecture & Capabilities

Engineered for speed and format accuracy.

Core capabilities built directly into Silencer v2.2.0 inside the private Engine Suite.

  1. 01

    C++17 Non-Causal BPM & Offset Engine

    Analyzes onset periodicity across the full track without causal phase lag, outputting exact BPM alongside sub-millisecond measure-zero offsets and Start/Total MADI boundaries.

  2. 02

    Automatic Format Routing & Silence Wav

    Toggle Silence Wav to route WAV files directly to silence-aligned OGG files while normalizing FLAC, MP3, and M4A sources to WAV cleanly.

  3. 03

    LUFS Loudness Normalization

    Built-in ITU-R BS.1770 integrated LUFS metering with a one-click -8.0 LUFS target chip so custom charts match consistent in-game playback levels.

  4. 04

    Sub-Millisecond Timing Editor

    Verify detected downbeats aurally with 1/4, 1/8, and 1/16 beat snap steps and ±0.001s manual trim adjustments before locking output filenames.

  5. 05

    Explorer Context Menu & Diagnostics

    Register or remove right-click Windows Explorer actions directly from settings and inspect every DSP pass inside the Catppuccin Diagnostics tab.

Closed Engine Launcher Deployment.

Why Silencer requires an approved Engine Launcher session rather than standalone public installer links.
