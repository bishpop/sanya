Launchers & Conversion Ecosystem.

01 · Ecosystem Launcher

Engine Launcher

Automated desktop manager and execution gateway for BeatUp Engine client instances. Handles delta patching, asset integrity checking, and isolated runtime profiles.

Restricted Utility — No Public Download

The Engine Launcher is maintained strictly for private development and automated integration testing with internal builds (including v1.3+). It is not distributed publicly.

  1. 01

    Differential Delta Patching

    Instead of redownloading full multi-hundred megabyte archives, the launcher calculates binary diffs against remote manifests and applies only modified byte streams, minimizing patch bandwidth and setup delays.

  2. 02

    Runtime Integrity & Verification

    Performs background SHA-256 validation across engine binaries, SDL2 dynamic libraries, sound banks, and core font packages prior to game execution to preemptively stop missing-asset crashes.

  3. 03

    Multi-Instance & Profile Switching

    Facilitates simultaneous side-by-side installations of different engine iterations (such as verifying legacy v1.2 projects alongside experimental v1.3 builds) with independent configuration trees.

  4. 04

    Uninstall Manager & Chart Protection

    Built-in uninstall manager for all ecosystem suite tools with safety confirmation dialogs and absolute protection for user data, custom charts, and personal offset calibrations.

  5. 05

    Automated Crash Telemetry

    Hooks into process exit codes to capture crash mini-dumps, memory allocations, and hardware display adapter states, generating actionable bug reports for maintainers.

02 · Dedicated Launcher

One Two Party Launcher

Specialized client launcher engineered exclusively for One Two Party (OTP) game sessions, competitive server routing, and rapid song pack indexing.

Restricted Utility — No Public Download

One Two Party Launcher is tailored for private tournament administration and server relay testing. Public downloads and distribution packages are not available.

  1. 01

    Dynamic Server Routing

    Switches between dedicated game server endpoints, private testing relays, and local network nodes with single-click profiles, avoiding any manual edits to local configuration files.

  2. 02

    Display & Input Buffer Tuning

    Initializes low-latency exclusive fullscreen display modes with native high-refresh rate support (60Hz, 120Hz, 144Hz+) and optimized raw input polling buffers tailored for OTP's strict rhythmic windows.

  3. 03

    Pack Linking & Fast In-Memory Cache

    Mounts external song packs directly without duplication, compiling a compact in-memory metadata index that accelerates chart and audio loading times during rapid multiplayer rotations.

  4. 04

    Session Isolation & Engine Handshake

    Coordinates directly with OTP Engine v0.2.1: ensures 1:1 NPC/Player move synchronization (GO/YEAH), quiet UI SFX, below-player FPS overlays, and isolated keymaps.

03 · Chart Conversion

Ballroom Converter

High-precision chart translation tool engineered specifically for SanBallroom Studio v1.0 and Ballroom game modes, coupled arrow matrices, and sub-tick timing synchronizations.

Restricted Tooling — No Public Download

The Ballroom Converter is an internal conversion utility utilized by chart designers for specialized choreography formats. It is not distributed publicly.

  1. 01

    Ballroom Step Matrix Mapping

    Translates intricate dual-character dance steps, synchronized directional pairs, and hold gestures that standard 4-key / 8-key BeatUp formats cannot natively accommodate.

  2. 02

    Sub-Tick Timing Preservation

    Maintains absolute micro-timing fidelity across dynamic BPM shifts, tempo slowdowns, and stop events, preventing audio-to-arrow sync drift throughout lengthy tracks.

  3. 03

    Sanity & Feasibility Inspection

    Automated verification sweeps identify physical impossibilities (such as contradictory directional strikes in identical frames) and syntax discrepancies prior to .slk compilation.

  4. 04

    Bi-Directional Schema Support

    Enables full two-way roundtripping: converts raw StepMania choreography files into Ballroom format and reverts compiled matrices back for visual inspection and audit verification.

04 · Distribution Policy

Why Access Is Restricted.

Clear boundaries between public, community-ready software releases and internal development utilities.

Strictly Closed Development

These three tools — along with BeatUp Engine v1.3 and onward — are developed for private testing, specialized tournament environments, and direct engine engineering. Public distribution would create fragmented versions, unintended dependency conflicts, and unsupported bug reports.

No download links, repository access, or binary distributions are provided for these utilities.

Public Software Available

Looking for public tools?

BeatUp Engine v1.2 and SanConverter v1.4.4 are complete, free, and open for everyone to download.
